THE WORKFLOW

From raw video to AI-selected cut and finished commentary, in one workspace.

Import once, let VideoMagic understand the footage, describe what you want kept, then continue into narration and timeline editing without leaving the desktop app.

01

Import

Drag in MP4, MOV, MKV, WEBM or M4V. Local analysis begins automatically and builds a timestamped scene index.

02

Describe the cut

Write “keep the funniest reactions” or “make a fast 20-second highlight”. The model selects only real scene IDs.

03

Add narration

Use Mandarin, American English or British English voices, then auto-time or manually place each sentence.

04

Render

FFmpeg/NVENC performs the cut, mix, subtitles, ducking and final MP4 with progress and cancel controls.

CREATOR TOOLS

Enough control to edit the story, without becoming a full NLE.

01

Natural-language AI editing

VideoMagic builds timestamped scene descriptions locally. Your prompt selects real scene IDs, explicit 15s/20s targets become hard duration budgets, and FFmpeg performs the actual cuts — the model never invents render timestamps.

01 · Intro 02 · Punchline
02

Source waveform

FFmpeg extracts a lightweight local waveform so narration can be placed around source-audio beats and quiet gaps.

03

Smart ducking

Source audio drops only while narration is speaking, using sidechain compression instead of lowering the whole clip.

04

Synchronized subtitles

Subtitle timing comes from the exact same narration timeline, then burns into the final H.264 render.

05

Persistent projects

Save native .vmagic projects with source, script, voice settings and manual timeline positions.

06

Warm local AI

The local worker stays alive between previews and renders so repeated voice generation does not reload the model every time.
