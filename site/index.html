THE WORKFLOW

From source clip to finished commentary, in one workspace.

The simple path stays simple. Use automatic timing when it is good enough, or open the creator timeline when you want control.

01

Import

Choose or drag in MP4, MOV, MKV, WEBM or M4V. VideoMagic probes duration and audio locally.

02

Write

Paste Mandarin narration and choose a local voice preset. Preview the voice before committing to a render.

03

Time it

Auto-spread sentences, or drag and resize narration blocks against the source-audio waveform.

04

Render

Generate voice, synchronized subtitles, source-audio ducking and the final MP4 with progress and cancel controls.

CREATOR TOOLS

Enough control to edit the story, without becoming a full NLE.

01

Visual narration timeline

Sentence-level blocks are real render inputs. Drag a block to move narration, pull either edge to change its timing window, or type exact start and end values.

01 · Intro 02 · Punchline
02

Source waveform

FFmpeg extracts a lightweight local waveform so narration can be placed around source-audio beats and quiet gaps.

03

Smart ducking

Source audio drops only while narration is speaking, using sidechain compression instead of lowering the whole clip.

04

Synchronized subtitles

Subtitle timing comes from the exact same narration timeline, then burns into the final H.264 render.

05

Persistent projects

Save native .vmagic projects with source, script, voice settings and manual timeline positions.

06

Warm local AI

The local worker stays alive between previews and renders so repeated voice generation does not reload the model every time.
