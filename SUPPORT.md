# Support

## Getting help

Before opening an issue:

1. Install the latest Windows release.
2. Check the open issues for the same problem.
3. Open **Settings & diagnostics** in VideoMagic and copy only the non-sensitive details that are relevant.
4. Never attach private source videos, credentials, tokens, or personal file paths unless you intentionally redact them.

Use the structured GitHub issue forms:

- **Bug report** for reproducible failures.
- **Feature request** for focused creator-workflow improvements.

For sensitive security problems, use the repository's private security reporting flow instead of a public issue.

## Current support scope

VideoMagic is currently Windows-first. The supported public path is the latest x64 Windows installer from GitHub Releases.

The core workflow is local-first. Cloud rendering, macOS distribution, code signing, auto-update, and custom voice cloning are not part of the current supported release boundary.
